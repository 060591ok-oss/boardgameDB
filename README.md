# Настільна навчальна гра «База даних»

Інтерактивна версія настільної гри з інформатики (9–11 класи, тема «Бази даних»).
Чистий HTML, CSS і JavaScript: без збирання, без залежностей, без сервера.

## Можливості
- Поле з 25 клітинок у змійці (старт, фініш, три кольори рівнів), 1–6 гравців або команд.
- Кидання кубика, покрокове переміщення фішок, картки трьох рівнів із таймером (30 / 60 / 90 с).
- Правильна відповідь: 1, 2 або 3 DataCoin. Неправильна або вихід часу: назад на 2 клітинки.
- Підказка за 1 DataCoin: текстова порада й дві прибрані хибні відповіді.
- Фінальне завдання на фініші, рейтинг, оцінка за 12-бальною шкалою, сертифікати для друку (A4, альбомна орієнтація).

## Запуск
Відкрийте `index.html` у браузері або опублікуйте на GitHub Pages:
1. Створіть репозиторій і завантажте всі файли з кореня проєкту.
2. Settings → Pages → Source: `main` / `(root)` → Save.
3. Гра відкриється за адресою `https://<ваш-логін>.github.io/<репозиторій>/`.

## Свої запитання
Відредагуйте `js/questions.js`. Рядок має вигляд
`[питання, правильна відповідь, хибна, хибна, хибна, підказка]`.
Порядок відповідей у грі перемішується. Рівні: `1`, `2`, `3`; фінальні завдання: `4`.

## Оцінка в сертифікаті
Підсумкова оцінка (1–12) = 70 % точності відповідей (із вагою рівня 1, 2, 3) + 30 % пройденого шляху; +0,5 бала за виконане фінальне завдання.
Параметри (штраф, вартість підказки, бонус, час) задано константами на початку `js/game.js`.

Шрифт Nunito підключається з Google Fonts; без інтернету гра використає системний шрифт.
